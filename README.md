# 🌆 Urbanfinity

Urbanfinity is a modern and responsive urban city website designed to showcase city life, architecture, lifestyle, and urban experiences through a clean and visually engaging interface. The project focuses on responsive web design, smooth navigation, and modern UI components to create an attractive city-themed website.

---

## 👉 Features

* Modern urban-themed landing page
* Responsive website layout
* Interactive navigation bar
* Hero section with engaging visuals
* Multiple content sections
* Smooth scrolling experience
* Clean UI/UX design
* Mobile-friendly interface
* Organized website structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* Flexbox & Grid Layouts
